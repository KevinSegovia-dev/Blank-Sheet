# 📚 Blank Sheet

A frontend digital library project designed to provide a simple and modern interface for browsing and exploring a collection of books.

## 🌐 Live Demo

You can visit the deployed version of the project on GitHub Pages:

[View Blank Sheet](https://kevinsegovia-dev.github.io/Blank-Sheet/)

## ✨ Features

* 📖 Browse a collection of books.
* 🔎 Search for books.
* 📝 View book information.
* 📱 Responsive design for different screen sizes.
* 🎨 Clean and simple user interface.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/KevinSegovia-dev/Blank-Sheet.git
```

### Navigate to the project

```bash
cd Blank-Sheet
```

### Run the project

Open `index.html` in your browser.

For development, you can also use **Live Server** in Visual Studio Code.

## 🌐 GitHub Pages

This project is deployed using GitHub Pages.

To deploy it yourself:

1. Open your repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select:

   * **Source:** Deploy from a branch
   * **Branch:** `main`
   * **Folder:** `/ (root)`
4. Click **Save**.
5. GitHub will generate a public URL for your project.
